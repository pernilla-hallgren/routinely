# 🌅 Routinely

A child-friendly routine tracker that helps kids independently
complete their morning and evening tasks.

Built with React, TypeScript, Jotai, and a custom component
library documented in Storybook.

> 🚧 Work in progress

## Tech stack

- React 18 + TypeScript
- Jotai (state management)
- Vite
- Storybook
- Cypress (E2E testing)
- pnpm workspaces (monorepo)
